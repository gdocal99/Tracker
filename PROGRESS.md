## Итерация 3 — 2026-07-24 (v0.69.0) — Переход на Firebase

База итерации — присланный `index_33.html` (v0.68.0), он новее и полнее того, что лежал в
репозитории (v0.44.0). Работал поверх него.

### Сделано
- [x] **#1 Firebase вместо Google Drive.** Модуль Google Drive удалён целиком (gapi/gis, Client ID,
  токены, ручная синхронизация). Вместо него — модуль `cloud` (Firebase v11 через ESM-import с CDN):
  Firebase Auth (Google Sign-In + Email/Password) и Cloud Firestore.
  - Структура: `users/{uid}/days/{ГГГГ-ММ-ДД}` — документ на день; `users/{uid}/meta/settings` — настройки.
  - Offline-First: LocalStorage — единственный источник правды для UI; облако — тихий фон.
    Пуш дней дебаунсится (2.5с), приём чужих правок — живой через `onSnapshot`. Свои записи
    (`hasPendingWrites`) при приёме пропускаются, эха/циклов нет. Оффлайн-правки уходят при сети.
  - Конфиг Firebase (не секретный) вставляется один раз в настройках → `meta.firebaseConfig`.
    `parseFirebaseConfig` понимает JSON, JS-объект со страницы Console (неквотированные ключи,
    висячие запятые), одинарные кавычки. Редактировать HTML не нужно.
  - Любая ошибка облака в try/catch — локальная работа не ломается никогда.
- [x] **#2 Field-level LWW.** Переиспользован существующий `mergeDayDeep` + `day.t` (`t["i:water"]`,
  `t["p:fajr"]`). Проверено: правки воды с телефона и намаза с ноута не затирают друг друга;
  при равной единице побеждает более свежая метка. Настройки — whole-object LWW по `metaUpdated`.
  Авто-снимки в LocalStorage сохранены как аварийный контур.
- [x] **#3 Экспорт → две кнопки:** «📋 Копировать отчёт для Claude» (сразу в буфер, модалка —
  фолбэк) и «💾 Скачать резервную копию (JSON)». Восстановление спрятано в свёрнутую секцию.
  В отчёт добавлена объективная автооценка дня рядом с ручной отметкой. Плотность отчёта
  (динамика, времена, пропуски, хронология, погода, симптомы, триггеры, «≈ Неточно», журнал
  блокировок) уже была — не тронута.
- [x] **#4/#5 UX.** Убран дубль настройки синхронизации; экспорт сведён к двум понятным кнопкам;
  добавлен тихий индикатор облака (точка слева от ⚙, цвет = состояние сети/облака). Жёсткая
  2-колоночная десктоп-сетка и дашборд (кольца/серии/блокировки/недельный график) уже
  соответствовали ТЗ — сохранены без поломок.
- [x] **#6 Анимации — 4 дофаминовых триггера:** все 5 намазов, 100% обязательного за день,
  «👑 Идеальный день», рост серии. Полноэкранный салют `bigCelebration()` + микро-эффект в
  границах кнопки. `prefers-reduced-motion` уважается.
- [x] **#7 Оценка дня — гибрид.** `dayQualification()` объективно считает квалификацию по
  % обязательного, числу намазов и наличию срывов (👑/🟢/🟡/🟠/🔴). На главном — тихая строка
  «Автооценка: …» с кнопкой «Принять» в один тап; ручные 👑/🔴 остаются. Минимум кликов,
  объективность сохранена.

### Не ломалось (по требованию ТЗ)
- Формулы баллов, времена намазов (координаты Ужгорода), норма воды, конструктор привычек,
  защита случайно закрытых дней — не тронуты. Рендер и работа с данными уже в try/catch с Rescue UI.

### Проверено (Playwright + Chromium)
- Экран рендерится, ошибок в консоли нет; настройки открываются; блок «Облачная синхронизация»
  на месте, «Google Drive» нигде нет; обе кнопки экспорта есть; отчёт строится; автооценка
  считается; салют и отметки не бросают исключений; LWW-слияние держит правки обоих устройств.

### На заметку
- Встроен конфиг проекта пользователя (`DEFAULT_FIREBASE_CONFIG`, проект `trac-b4f40`) — приложение
  работает «из коробки», нужно только войти в аккаунт. Можно переопределить своим проектом:
  ⚙ → «Облачная синхронизация» → «использовать свой проект Firebase».
- Добавлен `firestore.rules` — доступ только к своим `users/{uid}/**`. Применить в
  Firebase Console → Firestore → Rules (или `firebase deploy --only firestore:rules`).
- В проекте нужно включить Authentication (Google + Email/Password), создать Firestore и добавить
  домен хостинга в Authentication → Settings → Authorized domains (иначе Google-вход не откроется).
- Динамический ESM-import Firebase не работает при открытии по `file://` — нужен http(s)-хостинг.
